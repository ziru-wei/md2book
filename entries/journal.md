# Notes on Calm Everyday AI

This is ordinary body text with **bold**, *italic*, and ==highlighted text==.

A normal Markdown hyperlink such as [Calm Technology](https://calmtech.com/) becomes publication-style inline text with a numbered reference.

- First compact bullet.
- Second bullet with **emphasis**.
- Third bullet with ==highlighted text==.

### Teaser figure example

![image.png](https://picgocloud.com/m/39e6693e-6344-4d99-82f5-59cad2c624c6.png)
//teaser
(this figure depicts....)

The image above is promoted under the metadata because it's followed by `//teaser`, with an optional `(caption)` on the next line.

## Normal article image

The same syntax without the marker stays where it appears in the article:

![image.png](https://picgocloud.com/m/39e6693e-6344-4d99-82f5-59cad2c624c6.png)
(this figure depicts....)


A repeated link to [Calm Technology](https://calmtech.com/) reuses the same reference number.
